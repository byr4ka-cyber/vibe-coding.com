Новый язык для людей

ВАЙБ-КОДИНГ

Создавай приложения, скрипты и интерфейсы на естественном языке — без сложного синтаксиса. ВАЙБ-КОДИНГ понимает команды на русском, английском и генерирует рабочий код одним предложением.

No boilerplate, no setup. Просто скажи, что нужно, и система напишет код, соберёт UI и проверит результат.

Целевой домен проекта: vibecoding.ai — работа над сайтом продолжается.

Windows‑установщик macOS Linux Инструкция 
print Привет, мир!
set name to "Вайб"
if name contains Вайб then print "Я тебя слышу"
vibe create button "Нажми"

Новый рабочий процесс

Перестань писать шаблоны вручную. Вайб-Кодинг создаёт код по задаче, а не по правилам.

Интерактивный запуск

Редактируй команды, запускай REPL и проверяй результат сразу.

ИИ в центре

От запроса до рабочего сценария — OpenAI и локальный AI дополняют и исправляют код.

Пример 1

print Привет, мир!
set name to "Вайб"
if name contains Вайб then print "Готово!"

Пример 2

vibe create button "Нажми" with color blue
on click show "Приветствие"

Установить на любую систему

Windows macOS Linux

Для Windows скачай `vibe-setup.exe` и запусти его. Для macOS скачай `vibe-macos`, дай право на запуск и запусти chmod +x vibe-macos && ./vibe-macos. Для Linux скачай tar.gz, распакуй и запусти.

Публикация сайта

Чтобы сайт был доступен всем, размести папку site/ на GitHub Pages, Netlify, Vercel или любом статическом хостинге.

  • GitHub Pages: создай ветку gh-pages и выложи туда содержимое site/.
  • Netlify: просто перетащи папку site/ на сайт или подключи репозиторий.
  • Vercel: укажи каталог site как статическую папку.

После публикации можно привязать домен и тогда любой сможет открыть сайт.

Естественный язык

Пиши команды как обычный текст, без сложных скобок и объявлений типов.

ИИ-провайдеры

Работает с OpenAI и локальной моделью. Выбирай `openai` или `local`.

Простой CLI

Запускай `vibe` из терминала, пиши скрипты и тестируй интерактивно.

Что можно сделать прямо сейчас

Автоматизируй рутину

Опиши задачу на русском, и ВАЙБ-КОДИНГ создаст рабочий сценарий.

Генерируй интерфейс

Собери простое приложение из текста: кнопки, формы, логика и стиль.

Пиши с ИИ

Встроенная поддержка OpenAI и локального AI помогает дописывать код и исправлять ошибки.

Почему это интересно

ВАЙБ-КОДИНГ — это не просто новый синтаксис. Это продукт, который делает работу с кодом проще, быстрее и понятнее.

  • Напиши задачу, не код: алгоритм сам сформирует рабочий скрипт.
  • Мгновенный прототип: получи интерфейс и логику за пару строк.
  • Генерируй идеи: AI предлагает варианты и исправления прямо во время работы.
  • Всё на твоём языке: русский, английский, смешанные фразы.

Как начать

1. Скачай установщик

Windows: vibe-setup.exe macOS: vibe-macos Linux: vibe-linux.tar.gz

Самое быстрое начало — один клик загрузки и запуск.

2. Запусти

vibe repl

3. Экспериментируй

vibe --ai-provider local examples/local-ai.vibe
