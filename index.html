ВАЙБ-КОДИНГ

Пиши команды как обычный текст, а система сама превращает их в рабочий код. Поддержка OpenAI и локального AI.

Write commands like ordinary text and the system turns them into working code. Supports OpenAI and local AI.

Целевой домен проекта: vibecoding.ai (пример, пока не опубликован)

Windows‑установщик macOS Linux Инструкция 
print Привет, мир!
set name to "Вайб"
if name contains Вайб then print "Я тебя слышу"
vibe create button "Нажми"

Установить на любую систему

Windows macOS Linux

Для Windows скачай ZIP с `vibe-setup.exe`. Для macOS: скачай ZIP и запусти `vibe-macos`. Для Linux: скачай tar.gz, распакуй и дай право на запуск.

Публикация сайта

Чтобы сайт был доступен всем, размести папку site/ на GitHub Pages, Netlify, Vercel или любом статическом хостинге.

  • GitHub Pages: создай ветку gh-pages и выложи туда содержимое site/.
  • Netlify: просто перетащи папку site/ на сайт или подключи репозиторий.
  • Vercel: укажи каталог site как статическую папку.

После публикации можно привязать домен и тогда любой сможет открыть сайт.

Естественный язык

Пиши команды как обычный текст, без сложных скобок и объявлений типов.

ИИ-провайдеры

Работает с OpenAI и локальной моделью. Выбирай `openai` или `local`.

Простой CLI

Запускай `vibe` из терминала, пиши скрипты и тестируй интерактивно.

Как начать

1. Скачай установщик

Windows: vibe-windows.zip macOS: vibe-macos.zip Linux: vibe-linux.tar.gz

2. Запусти

vibe repl

3. Экспериментируй

vibe --ai-provider local examples/local-ai.vibe
