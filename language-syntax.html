Правила и команды ВАЙБ

Здесь описаны ключевые команды и как их писать правильно.

Команда print

Выводит текст в терминал или лог.

print Привет, мир!

Можно комбинировать текст и переменные:

set name to "Вайб" print Привет, name!

Команда set

Сохраняет значение в переменную.

set age to 18 set city to "Москва"

Условие if

Выполняет блок кода, если условие истинно.

if name contains Вайб then print "Привет, Вайб!" end

Команда vibe create

Создаёт интерфейс или элемент.

vibe create button "Нажми" with color blue

Добавь реакцию на клик:

on click show "Приветствие"

Структура блоков

Блоки открываются словом if и закрываются end. Внутри можно писать команды с отступами.
