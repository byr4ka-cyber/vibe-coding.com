Как скачать и запустить на Linux

Распакуй архив, сделай файл исполняемым и запусти ВАЙБ в терминале.

Шаги для Linux

  1. Скачай файл installers/vibe-linux.tar.gz.
  2. Распакуй архив: tar -xzf vibe-linux.tar.gz.
  3. Сделай бинарный файл исполняемым: chmod +x vibe.
  4. Запусти: ./vibe repl.

После этого ВАЙБ будет готов к приёму команд на естественном языке.
