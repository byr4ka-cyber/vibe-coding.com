Как скачать и запустить на Linux

Распакуй архив, сделай файл исполняемым и запусти ВАЙБ в терминале.

Шаг 1. Скачать архив

Скачай файл installers/vibe-linux.tar.gz. Открой терминал и перейди в папку, где он оказался, например:

cd ~/Downloads

Шаг 2. Распаковать

Выполни команду:

tar -xzf vibe-linux.tar.gz

Если архив создаёт папку, проверь её командой ls и перейди внутрь:

cd имя_папки

Шаг 3. Сделать исполняемым

Убедись, что файл называется vibe или похожим именем, и установи права:

chmod +x ./vibe

Шаг 4. Запустить

Запусти программу:

./vibe repl

Если появится ошибка «Permission denied», повтори команду chmod +x ./vibe и попробуй снова.

Шаг 5. Использовать командную строку

Да, на Linux всё делается через консоль. После запуска REPL ты будешь вводить команды так:

print Привет, мир! set name to "Вайб" if name contains Вайб then print "Готово!" end

Чтобы выйти из режима, нажми Ctrl+C.
