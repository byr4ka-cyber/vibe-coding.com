Язык ВАЙБ

Как пользоваться языком ВАЙБ

Простой язык, где команды пишутся как обычный текст.

Примеры команд

С помощью ВАЙБ ты описываешь поведение, а не структуру кода.

print Привет, мир! set name to "Вайб" if name contains Вайб then print "Готово!" end vibe create button "Нажми" with color blue on click show "Приветствие"

Это простая основа: описывай, что должно произойти, и ВАЙБ превратит это в рабочий сценарий.
