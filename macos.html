Как скачать и запустить на macOS

Скачай исполняемый файл и запусти его из терминала после установки прав.

Шаг 1. Скачать файл

Скачай installers/vibe-macos. Обычно он окажется в папке "Загрузки".

Шаг 2. Открыть Терминал

Запусти "Терминал" и перейди в папку, где лежит файл, например:

cd ~/Downloads

Шаг 3. Сделать файл исполняемым

Выполни команду:

chmod +x vibe-macos

Шаг 4. Запустить

Запусти ВАЙБ так:

./vibe-macos repl

Если Mac сообщит, что файл не может быть открыт, открой "Системные настройки" → "Безопасность и конфиденциальность" и нажми «Разрешить». Затем повтори запуск.

Шаг 5. Работать в REPL

Пиши команды по одной строке, например:

print Привет, мир!

Чтобы выйти, нажми Ctrl+C в терминале.
