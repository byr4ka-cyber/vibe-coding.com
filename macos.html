Как скачать и запустить на macOS

Скачай исполняемый файл и запусти его из терминала после установки прав.

Шаги для macOS

  1. Скачай файл installers/vibe-macos.
  2. Открой Терминал и сделай файл исполняемым: chmod +x vibe-macos.
  3. Запусти: ./vibe-macos repl.
  4. Пиши команды на языке ВАЙБ прямо в терминале.

Если появится запрос доступа к исполнению, разреши его в настройках безопасности.
