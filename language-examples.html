Примеры

Примеры работы на языке ВАЙБ

Смотри, как выглядят реальные команды и сценарии для задач.

Пример 1: вывод текста

print Привет, мир!

Эта команда сразу показывает текст.

Пример 2: переменная и условие

set name to "Вайб" if name contains Вайб then print "Привет, Вайб!" end

Используй set для хранения значений и if для проверки.

Пример 3: интерфейс с кнопкой

vibe create button "Нажми" with color blue on click show "Приветствие"

Это создаёт кнопку и показывает текст при нажатии.

Пример 4: выполнение нескольких действий

print Начинаем процесс set count to 3 if count > 0 then print "Осталось: " + count end

Команды выполняются последовательно одна за другой.
