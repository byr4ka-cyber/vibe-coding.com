Как пользоваться языком ВАЙБ

Пиши понятные команды, а ВАЙБ превратит их в рабочие действия.

Что такое язык ВАЙБ

ВАЙБ — это язык, где команды пишутся как обычный текст. Описывай задачу, а система выполняет её.

Основные правила

  • Каждая команда на новой строке.
  • Используй set имя to "значение" для переменных.
  • Условия пишутся как if ... then, а заканчиваются end.
  • Интерфейс создаётся через vibe create ....

Пример 1: вывод текста

print Привет, мир!

Пример 2: переменная и условие

set name to "Вайб" if name contains Вайб then print "Готово!" end

Пример 3: кнопка

vibe create button "Нажми" with color blue on click show "Приветствие"

Как использовать

Пиши команды по одной строке и нажимай Enter в REPL. Если нужно изменить поведение, просто исправь текст и выполни заново.
