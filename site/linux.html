Как скачать и запустить на Linux

Распакуй архив, сделай файл исполняемым и запусти ВАЙБ в терминале.

Шаг 1. Скачать архив

Скачай файл installers/vibe-linux.tar.gz и открой терминал.

Шаг 2. Распаковать

Перейди в папку, где находится файл, например:

cd ~/Downloads

Распакуй архив:

tar -xzf vibe-linux.tar.gz

Шаг 3. Сделать файл исполняемым

Если после распаковки в текущей папке есть файл vibe, выполни:

chmod +x ./vibe

Шаг 4. Запустить

Запусти программу:

./vibe repl

Если архив распаковал папку, сначала перейди в неё: cd имя_папки.

Что дальше

Теперь ВАЙБ готов принимать команды. Пример:

print Привет, мир!
