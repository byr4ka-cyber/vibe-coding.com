Правила и команды ВАЙБ

Здесь описаны ключевые команды и правила, чтобы писать правильно.

Команда print

Выводит текст или переменные на экран.

print Привет, мир!

Комбинируй текст и переменные:

set name to "Вайб"
print Привет, name!

Команда set

Сохраняет значение в переменную.

set age to 18
set city to "Москва"

Условия if

Исполняет блок кода, когда условие истинно.

if age > 17 then
  print "Вход разрешён"
end

Проверка текста:

if city == "Москва" then
  print "Столица"
end

Операторы сравнения

  • == — равно
  • != — не равно
  • > — больше
  • < — меньше

Создание интерфейса

vibe create создаёт визуальные элементы.

vibe create button "Нажми" with color blue
on click show "Приветствие"

Сначала задаётся элемент, потом — реакция на событие.

Структура блоков

Блоки начинаются с if и заканчиваются end.

if score >= 100 then
  print "Победа!"
end

Функции и повторение

Если язык поддерживает функцию, она позволяет повторно использовать код.

define greet person
  print Привет, person!
end

greet "Маша"
