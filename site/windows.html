Как скачать и установить на Windows

Загрузи установщик и запусти его. Потом используй команду vibe repl для запуска.

Шаг 1. Скачать установщик

Скачай файл installers/vibe-setup.exe через кнопку на странице или прямо по ссылке. Если браузер спрашивает, разрешить загрузку, выбери "Сохранить".

Шаг 2. Установить

  1. Открой папку, куда загрузился файл, обычно это "Загрузки".
  2. Дважды кликни по файлу vibe-setup.exe.
  3. Подтверди запуск и следуй подсказкам установщика.
  4. Дождись завершения установки.

Шаг 3. Запустить

Открой PowerShell или командную строку и введи:

vibe repl

Если терминал сообщает, что команда не найдена, закрой окно и открой новый — после установки путь обновляется.

Если Windows блокирует запуск, нажми «Дополнительно» и «Выполнить в любом случае».

Что дальше

Когда откроется REPL, ты можешь сразу писать команды:

print Привет, мир!

Чтобы выйти, нажми Ctrl+C.
