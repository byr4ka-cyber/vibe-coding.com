Примеры

Примеры работы на языке ВАЙБ

Смотри, как выглядят реальные команды и сценарии для разных задач.

Пример 1: вывод текста

print Привет, мир!

Простая команда, чтобы сразу увидеть результат.

Пример 2: переменная и условие

set name to "Вайб"
if name contains Вайб then
  print "Привет, Вайб!"
end

Здесь name хранит значение, а if проверяет условие.

Пример 3: интерфейс с кнопкой

vibe create button "Нажми" with color blue
on click show "Приветствие"

Это создаёт кнопку и показывает сообщение при клике.

Пример 4: счётчик

set count to 1
print Текущий счёт: count
set count to count + 1
print Новый счёт: count

Вайб позволяет изменять значения и показывать их снова.

Пример 5: простое меню

vibe create button "Старт"
vibe create button "Настройки"
on click show "Вы выбрали Старт"
on click show "Вы выбрали Настройки"

Так можно создавать простое меню и обрабатывать нажатия.

Пример 6: бот и API

set token to "ВАШ_ТОКЕН"
set chat_id to "123456789"
set text to "Привет от ВАЙБ-бота"
http post "https://api.telegram.org/bot" + token + "/sendMessage" with json {
  "chat_id": chat_id,
  "text": text
}

Это пример, как отправить сообщение через Telegram API. Для реального бота добавляй обработку входящих обновлений.
