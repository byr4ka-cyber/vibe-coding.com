Основы языка

Как начать писать на ВАЙБ

ВАЙБ работает как разговорный язык: коротко, понятно и без сложного синтаксиса.

Главные правила

  • Каждая команда начинается с новой строки.
  • Используй простые ключевые слова: print, set, if, vibe create.
  • Всё выполняется последовательно, сверху вниз.
  • Текст между кавычками остаётся строкой, а без кавычек используется как имя переменной.

Пример базовой программы

set user to "Маша"
print Привет, user!

Здесь user — это переменная, которую мы используем внутри команды print.

Переменные

Переменная хранит значение, которое можно использовать повторно.

set age to 18
set city to "Москва"
print user + " из " + city

Последовательность

Вайб выполняет команды одну за другой. Сначала создаётся переменная, затем её значение используется.

Пример с вводом

Если язык поддерживает ввод пользователя, это выглядит так:

print Введите ваше имя
set name to input
print Привет, name!

Частые ошибки

  • Забыл кавычки вокруг текста.
  • Обратился к переменной до её создания.
  • Использовал неправильный синтаксис команды.

Что делать дальше
