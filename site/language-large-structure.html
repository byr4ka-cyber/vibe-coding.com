Структура проекта

Как строить большие проекты на ВАЙБ

Разбивай проект на файлы и модули, чтобы он оставался понятным и удобным для правки.

Почему структура важна

Когда проект становится большим, всё быстро усложняется. Если смешать интерфейс, логику и связь с сервисами в одном файле, его трудно поддерживать.

Поэтому лучше разделить проект на части: интерфейс, логику, внешний доступ и защиту.

Типовая структура

  • main.vibe — главный файл, который запускает приложение.
  • ui.vibe — пользовательский интерфейс: кнопки, экраны, меню.
  • logic.vibe — вычисления, правила, проверки.
  • bot.vibe — работа с Telegram, API и сетевыми запросами.
  • anti_cheat.vibe — правила и проверки для защиты от читов.

Как подключать части

Если язык поддерживает импорт, используй его. Если нет, запускай файлы последовательно и передавай данные через переменные.

Например, main.vibe может сначала запустить ui.vibe, потом logic.vibe, а затем bot.vibe.

Пример главного файла

import ui.vibe
import logic.vibe
import bot.vibe

start ui
run logic
start bot

Если импорт невозможен, можно просто держать порядок запуска и общие переменные.

Как хранить данные

Для больших проектов удобно хранить данные в понятных переменных или структурах. Например, состояния пользователей и настройки можно положить в один файл.

set settings to {
  "max_speed": 300,
  "bot_token": "ВАШ_ТОКЕН"
}
set user_state to {}

Проверяй каждый модуль

Разделяй работу на модули, тестируй одно задание, затем переходи к следующему. Это позволит быстро найти и исправить ошибку.
