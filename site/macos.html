Как скачать и запустить на macOS

Скачай исполняемый файл и запусти его из терминала после установки прав.

Шаг 1. Скачать файл

Скачай installers/vibe-macos. Обычно файл окажется в папке "Загрузки".

Шаг 2. Подготовить файл

Открой Терминал и перейди в папку загрузок, например:

cd ~/Downloads

Сделай файл исполняемым:

chmod +x vibe-macos

Шаг 3. Запустить

Запусти ВАЙБ командой:

./vibe-macos repl

Если Mac не разрешает запуск, открой "Системные настройки" → "Безопасность и конфиденциальность" и нажми "Разрешить" для этого приложения.

Что дальше

Когда видишь приглашение REPL, можешь писать команды:

print Привет, мир!

Чтобы выйти, нажми Ctrl+C.
