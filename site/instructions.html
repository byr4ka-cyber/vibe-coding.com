Windows — как скачать

Нажми кнопку на главной странице или скачай прямо файл:

Скачать для Windows

После загрузки запусти установщик и следуй подсказкам. После установки открой терминал и введи:

vibe repl

Это запустит интерактивный режим, где можно сразу писать команды на языке ВАЙБ.

macOS — как скачать

Скачай файл:

Скачать для macOS

Затем открой Терминал и сделай файл исполняемым:

chmod +x vibe-macos

После этого запусти:

./vibe-macos repl

Теперь ты можешь писать команды напрямую в терминале.

Linux — как скачать

Скачай архив:

Скачать для Linux

Распакуй архив в терминале:

tar -xzf vibe-linux.tar.gz

Сделай файл исполняемым и запусти:

chmod +x vibe ./vibe repl

После этого ВАЙБ готов принимать команды.

Как пользоваться языком ВАЙБ

Пиши запросы понятным текстом, и ВАЙБ преобразует их в рабочие команды и интерфейсы.

Примеры:

print Привет, мир! set name to "Вайб" if name contains Вайб then print "Готово!" end vibe create button "Нажми" with color blue on click show "Приветствие"

Начни с простого описания задачи, а затем усложняй сценарий шаг за шагом.
