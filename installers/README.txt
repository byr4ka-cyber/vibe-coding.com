Vibe-Coding Installers

Для создания бинарных файлов используйте npm run build, а затем файлы из dist/

Windows:
  dist/vibe-setup.exe -> архив dist/installers/vibe-windows.zip
macOS:
  dist/vibe-macos -> архив dist/installers/vibe-macos.zip
Linux:
  dist/vibe-linux -> архив dist/installers/vibe-linux.zip и dist/installers/vibe-linux.tar.gz

Linux: распакуйте tar.gz и дайте право на запуск:
  tar -xzf vibe-linux.tar.gz
  chmod +x vibe-linux

Windows: распакуйте ZIP и запустите vibe-setup.exe.
