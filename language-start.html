Основы языка

Как начать писать на ВАЙБ

ВАЙБ работает как разговорный язык: коротко, понятно, без сложного синтаксиса.

Главные правила

  • Каждая команда начинается с новой строки.
  • Используй простые ключевые слова: print, set, if, vibe create.
  • Всё выполняется по порядку, сверху вниз.
  • Текст между кавычками остаётся строкой.

Пример базовой программы

set user to "Маша" print Привет, "user"!

В этой программе мы сохраняем имя в переменную и затем выводим приветствие.

Как читать команды

Команда set задаёт значение переменной:

set name to "Вайб"

Команда print выводит текст на экран:

print Привет, мир!
