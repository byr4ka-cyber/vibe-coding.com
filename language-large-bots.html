Telegram‑боты

Как создавать большие Telegram‑боты на ВАЙБ

Боты — хорошая задача для больших проектов. ВАЙБ может отправлять и получать сообщения, обрабатывать команды и держать состояние.

Что нужно для бота

  1. Зарегистрируй бота у @BotFather и получи токен.
  2. Сохрани токен в переменной, чтобы использовать его в запросах.
  3. Напиши обработку команд и ответов.
  4. Запусти бот на машине, которая может работать постоянно.

Пример отправки сообщения

set token to "ВАШ_ТОКЕН"
set chat_id to "123456789"
set text to "Привет! Это бот на ВАЙБ."
http post "https://api.telegram.org/bot" + token + "/sendMessage" with json {
  "chat_id": chat_id,
  "text": text
}

Это базовый пример. Для настоящего бота нужно обрабатывать входящие сообщения.

Обработка команд

Бот получает сообщения и выбирает, что ответить. Часто используются команды /start, /help, /menu.

set updates to http get "https://api.telegram.org/bot" + token + "/getUpdates"
if updates contains "/start" then
  http post "https://api.telegram.org/bot" + token + "/sendMessage" with json {
    "chat_id": chat_id,
    "text": "Привет! Я готов помочь."
  }
end

В реальном боте полезно сохранять состояние пользователя, чтобы отвечать по-разному.

Хранение состояния

Большие боты не только отвечают, но и помнят, что делал пользователь.

set user_state to {}
set user_state[user_id] to "waiting_for_name"
if updates contains "Привет" then
  set user_state[user_id] to "menu"
end

Такую информацию удобно хранить в словаре или наборе переменных.

Как делить бот на части

  • bot.vibe — отправка/приём сообщений.
  • commands.vibe — обработка команд и сценариев.
  • storage.vibe — состояние пользователей и настройки.

Так бот остаётся удобным для расширения: добавил команду — и не тронул основную логику.
