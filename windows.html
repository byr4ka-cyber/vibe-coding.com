Как скачать и установить на Windows

Загрузи установщик и запусти его. Потом используй команду vibe repl для запуска.

Шаг 1. Скачать установщик

Скачай файл installers/vibe-setup.exe через кнопку на странице или прямую ссылку.

Шаг 2. Запустить установку

  1. Открой папку "Загрузки" или ту, куда скачался файл.
  2. Дважды кликни на vibe-setup.exe.
  3. Подтверди разрешения Windows и нажми «Далее».
  4. Когда установка закончится, закрой мастер.

Шаг 3. Запустить из терминала

Открой PowerShell или командную строку и введи:

vibe repl

Если команда не найдена, закрой окно и открой новый. Это обновит переменные окружения.

Шаг 4. Работать в REPL

В режиме REPL введи простую команду:

print Привет, мир!

Чтобы выйти, нажми Ctrl+C.
