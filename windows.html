Как скачать и установить на Windows

Загрузи установщик и запусти его. Потом используй команду vibe repl для запуска.

Шаги для Windows

  1. Нажми кнопку «Скачать для Windows» или открой файл installers/vibe-setup.exe.
  2. Запусти скачанный установщик vibe-setup.exe.
  3. Следуй подсказкам мастера установки.
  4. После установки открой терминал и введи vibe repl.

Теперь ты готов писать команды на языке ВАЙБ и запускать их сразу.
